#### Домашнее задание к работе 10
## Условие задачи
оставьте программу, которая для заданной пользователем фигуры, например прямоугольника (треугольника или другой фигуры см. индивидуальное задание работы 9) предлагает меню выбора одной из операций:
1) рассчитать площадь;
2) вывести определение фигуры;
3) нарисовать фигуру.

## 1. Алгоритм и блок-схема

Алгоритм

Начало

1. Запросить у пользователя радиус r с помощью функции get_radius().
Вывести текстовое меню с четырьмя пунктами.

2. Считать выбор пользователя (choice).
   
3. В зависимости от выбора (оператор switch):
1) Если 1: Вычислить площадь с помощью area_trapezoid(r) и вывести её.
2) Если 2: Вызвать print_definition() для вывода текста.
3) Если 3: Запросить символ для рисования, вызвать draw_trapezoid(r, symbol).
4) Если 4: Запросить второй радиус r2, вычислить разницу площадей через compare_trapezoids(r, r2).
    Если разница > 0 — первая больше.
    Если разница < 0 — вторая больше.
    Если = 0 — площади равны.

4. Завершить программу.
